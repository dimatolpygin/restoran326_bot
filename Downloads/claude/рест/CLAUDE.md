# CLAUDE.md — ИИ-бот Numero Uno Steakhouse

Проект: ИИ чат-бот для сети стейк-хаусов в Валенсии (3 заведения). Клиент —
OlegValencia (Kwork). Сайт https://numerounosteakhouse.com/ (Тильда, ES/EN),
бронирование через Ágora Bookings, WhatsApp один номер на 3 ресторана.

Сейчас в работе — **только демо** (инструмент закрытия сделки). Полный проект
разворачиваем после согласия клиента. Стек демо: Node.js + Vercel (страница +
serverless `/api/chat`), ИИ через OpenRouter.

## Состав демо (ТЗ, зафиксировано с клиентом)

Одна веб-страница (чат по ссылке), стилизованная под их сайт. Бот умеет:

1. **Живой диалог, не кнопки.** Свободная человеческая речь, без «выберите 1 или 2».
   Это главный критерий клиента (он спрашивал об этом прямо).
2. **Язык ES/EN.** Определяет язык гостя по сообщению и отвечает на нём.
3. **Вопросы по меню и часам.** Отвечает по реальному меню и часам (13–16, 19–24).
4. **Диалог брони по шагам:** ресторан (их три) → дата → время → число гостей → имя.
   Бот сам ведёт, разводит 3 заведения, ничего не упускает.
5. **Финал со связкой Ágora.** Сводка брони + кнопка «Подтвердить», ведущая на их
   живой виджет Ágora нужного ресторана с предзаполненной датой (`?date=YYYY-MM-DD`).
   Показывает, что бронь уходит в их систему и гость получит письмо. Без реальной записи.

## Как ИИ отвечает по меню/вину (формат хранения)

Меню на сайте было картинкой (макет A3), текст уже извлечён и лежит в файлах ниже.
Для демо БД/RAG НЕ нужны: вся база (меню + стейки + вино + рестораны) влезает в контекст.
Код при каждом запросе склеивает системный промпт из нужных файлов и шлёт в OpenRouter,
с инструкцией «отвечай только по этим данным, не выдумывай блюд, вин и цен».

Данные делятся на два вида:
- **Знания для модели** (меню, стейки, вино) → markdown, идут в системный промпт.
- **Структурные данные ресторанов** (id, адрес, часы, телефон, ссылка на виджет Ágora)
  → JSON (`data/restaurants.json`), используются кодом для сборки финальной ссылки брони.
