OlegValencia (Kwork). Сайт https://numerounosteakhouse.com/ (Тильда, ES/EN),

serverless `/api/chat`), ИИ через OpenRouter.

## Состав демо (ТЗ, зафиксировано с клиентом)

Одна веб-страница (чат по ссылке), стилизованная под их сайт. Бот умеет:

1. **Живой диалог, не кнопки.** Свободная человеческая речь, без «выберите 1 или 2».
   Это главный критерий клиента (он спрашивал об этом прямо).
2. **Язык ES/EN.** Определяет язык гостя по сообщению и отвечает на нём.
3. **Вопросы по меню и часам.** Отвечает по реальному меню и часам (13–16, 19–24).
4. **Диалог брони по шагам:** ресторан (их три) → дата → время → число гостей → имя.
   Бот сам ведёт, разводит 3 заведения, ничего не упускает.
5. **Финал со связкой Ágora.** Сводка брони + кнопка «Подтвердить», ведущая на их
   живой виджет Ágora нужного ресторана с предзаполненной датой (`?date=YYYY-MM-DD`).
   Показывает, что бронь уходит в их систему и гость получит письмо. Без реальной записи.

## Меню: где лежит и как оформляем в базу знаний

**Источник.** Меню на сайте — это НЕ текстовый PDF, а картинка (макет A3):
- Основное меню (ES): https://numerounosteakhouse.com/carta — файл
  `ESP_297420_A3_CARTA_.jpg.webp` (Tilda CDN). Английская версия — аналогичная
  картинка на EN-странице сайта.
- Карта вин: https://numerounosteakhouse.com/carta-de-vino (тоже изображение).

**Как готовим (этап 1).** Раз это картинка, текст надо ИЗВЛЕЧЬ:
1. Скачать изображения меню (ES + EN, при «меню всё» — и вино).
2. Прогнать через vision-модель (можно ту же на OpenRouter) или OCR → получить
   структурированный текст: категории, блюда, состав, цены.
3. Сверить извлечённый текст глазами (OCR по картинке может врать в цифрах/акцентах).
4. Сохранить как текстовые файлы в репо: `data/menu.es.md`, `data/menu.en.md`
   (+ `data/wine.md` при необходимости).

**Как ИИ отвечает по меню.** Для демо БД/RAG НЕ нужны. Меню одного ресторана целиком
влезает в контекст модели, поэтому весь текст меню (нужного языка) кладём в системный
промпт при каждом запросе к OpenRouter, с инструкцией «отвечай только по этому меню,
не выдумывай блюд и цен». Просто, точно, дёшево.

**Меню берём ПОЛНОЕ** (вся карта целиком), не выжимку.
