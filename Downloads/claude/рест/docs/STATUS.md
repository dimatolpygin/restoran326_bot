## Известные блокеры

Нет. Прод проверен end-to-end (2026-07-14): дизайн (десктоп+мобилка) принят,
ИИ отвечает, бронь доводит до виджета Ágora с датой.

**Важно про OpenRouter**: демо работает на балансе аккаунта OpenRouter. Системный
промпт ~8.3k токенов (полная база: меню+стейки+вино+рестораны). На НУЛЕВОМ балансе
OpenRouter режет промпт до ~4k → ошибка 402 "Prompt tokens limit exceeded" и ИИ
падает. Нужен положительный баланс (сейчас пополнен). Ключ и модель — env-переменные
в Vercel (в код/репо не уходят). При смене ключа: `vercel env rm/add OPENROUTER_API_KEY
production` + `vercel --prod`.

## Протокол обновления

**Старт сессии**: читать этот файл → `git tag -l "stage-*"` (сверить с таблицей) →
`git log --oneline -10` → открыть ROADMAP на текущем этапе → работать.

**Взятие этапа**: обновить «Текущий этап» и «Активную работу» → 🚧 в таблице →
коммит `chore(status): start stage N`.

**Закрытие этапа**: все чекбоксы `[x]` и проверены → `git tag stage-N-done -m "..."`
→ ✅ + тег + коммит + дата в таблице → запись в «Историю закрытий» → новый текущий
этап → коммит `chore(status): close stage N`.
